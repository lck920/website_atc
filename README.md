# Against The Current - Fan Website 🎸

Welcome to my very first website project! This is a fan-made website dedicated to my favorite band, **Against The Current**. 

I created this project to practice and learn web development basics while sharing my love for their music.

## 🌟 Features
The website consists of four main pages:
* **Home Page** (`index.html`): Features the band's header, a call-to-action for their latest album, and a list of upcoming tour dates.
* **About Page** (`about.html`): Information about the band and their journey.
* **Store Page** (`store.html`): A merchandise store prototype featuring items you can add to a shopping cart (powered by `store.js`).
* **Credits Page** (`credits.html`): Acknowledgments and credits for the resources used in this project.

## 💻 Technologies Used
* **HTML5**: For the structure and content of the web pages.
* **CSS3**: For styling, layout, and visual presentation (`styles.css`).
* **JavaScript**: For the interactive shopping cart logic on the store page (`store.js`).

## 🚀 How to Run Locally
Since this is a static website, you don't need any special servers or build tools to run it. 

1. Clone this repository or download the ZIP file.
2. Extract the files if downloaded as a ZIP.
3. Simply double-click on `index.html` to open it in your default web browser. 
4. Use the navigation bar at the top to explore the different pages.
